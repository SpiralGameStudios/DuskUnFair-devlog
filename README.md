# Dusk UnFair — блог разработки

Кооперативный экшен-рогалик на 1–4 игроков с видом сверху под углом: три яруса подземелья одним забегом, три класса с десятками умений, толпы монстров, элита и боссы, предметы и уровни, сеть через Steam. Мир целиком трёхмерный. Первый релиз — приоритет студии. Игра работает на движке [dfn](https://github.com/SpiralGameStudios/dfn-devlog).

## Что уже есть

- Забег: три яруса подряд, ворота логова, босс каждого яруса, лестница вниз, привал в святилище, экран итога.
- Три класса с оружием в руках (меч и щит, лук, посох), 20 умений по слотам, рывок с неуязвимостью, зелья на быстрых клавишах.
- Девять типов монстров, элита с аффиксами, три босса (Атаман Кривой Нож, Мать трясины, Владыка сумрака) — первые фазы.
- Предметы четырёх редкостей с аффиксами, лут с врагов и из сундуков, инвентарь с подсказкой и сравнением, опыт и 15 уровней.
- Читаемость боя: полоски здоровья, числа урона, полоса босса, кольцо под целью, частицы, тряска камеры, реакции и смерти клипами.
- Звук: удары, касты, шаги по материалу яруса, окружение и костёр, реверб по ярусу.
- Кооп: хост авторитетен; клиент видит лут, сундуки, опыт, элиту, бой босса, эффекты; вход по адресу из меню.
- Запуск одной командой (`scripts/play.sh`), переносимый билд для другой машины (`scripts/package.sh`), 40+ автоматических приборов без окон.

## Записи

- **2026-09-29, ночь.** **Первый кооп втроём через интернет** — через Steam, два друга и хост на Windows: 19 минут без единого обрыва, все три яруса, вход через лобби и ретрансляторы Steam. Спасибо за 27 замечаний — к утру большая часть уже в выпуске **0.4.4**. Вход и сеть: SteamID вставляется из буфера (Ctrl/Cmd+V), курсор не пропадает после матча, по Tab — список игроков с именами Steam, классом, здоровьем и пингом, пинги в мире по Ctrl+ЛКМ (кольцо, звук, метка на миникарте), «Пригласить друга» в паузе и лобби, на «Присоединиться» — список друзей, которые хостят (вход одним кликом), сверка версий при входе, переподключение в забег с сохранением места и сумки. В игре: вагонетки, ящики и бочки ломаются — с обломками и лутом; у предметов свои значки и описания с числами, лавка как в Dota (сетка по разделам, рекомендуемое слева), предметы на земле выглядят по типу; «повержен» — союзник поднимает с полоской прогресса; враги показывают замах перед ударом; спуск на ярус в 5 раз быстрее. Вид: палитра ярусов без пережога факелов — стены видны, тепло огня осталось; стены скалы идут одной лентой без наложений; курсор системный и не тормозит вместе с кадром; полный экран на Windows и Mac. Лаунчер: **самообновление** на обеих ОС, после падения игры предлагает отправить логи.
